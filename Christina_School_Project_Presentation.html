Project Overview

This project is NOT just a simple static school portfolio. It is a robust, dynamic Web Application designed to digitize school administration and communication.

  • Comprehensive Admin Dashboard
  • Full CRUD (Create, Read, Update, Delete) capabilities for all data
  • Dynamic public-facing portal driven by the database
  • Real-time updates to announcements, news, and galleries

Technology Stack

🎨 Frontend

Angular 21 TypeScript Tailwind/CSS3

⚙️ Backend

.NET 10 C# REST APIs

🗄️ Database & Storage

SQL Server Entity Framework Core
